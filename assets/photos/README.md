# 📷 Photo Instructions

To display your personal photos on the website, simply add your images to this folder (`assets/photos/`) with the following file names:

- **`photo01.jpg`** (or `.png` / `.webp`): Displayed in the **Apology Section** inside the Polaroid frame.
- **`photo02.jpg`** (or `.png` / `.webp`): Displayed in the **Final Section** at the bottom of the letter.
- **`photo03.jpg`** (Optional): Displayed in the memory tags or scrapbook section.

### Tips for Best Visual Results:
1. **Aspect Ratio**: Standard portrait or square photos (e.g. 4:5, 3:4, or 1:1) look best in the Polaroid frames.
2. **File Formats**: `.jpg`, `.jpeg`, `.png`, or `.webp` are supported.
3. **Resolution**: Images between 800px to 1600px wide provide crisp quality without slowing down mobile performance.
4. **Fallback**: If an image is not found, the website gracefully falls back to the embedded handcrafted scrapbook illustration placeholders.
