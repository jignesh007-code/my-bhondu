# 🎵 Music Instructions

To play a song of your choice on the website:

1. Add your audio file into this folder (`assets/audio/`) and name it:
   - **`song.mp3`** (or `.m4a` / `.wav` / `.ogg`)
2. If you want to change the song title displayed on the player, open `index.html` and edit the text inside `<span class="song-title">Our Song</span>`.
3. **Built-in Fallback**: If you haven't added an audio file yet, the built-in gentle lo-fi acoustic piano synthesizer will play a soothing, calm chord progression when you click Play, so the player is 100% interactive and functional immediately!
